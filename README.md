# Retail Sales Performance Dashboard

## Project Overview
An interactive Retail Sales Performance Dashboard developed using Microsoft Excel to analyze sales data and generate business insights.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel Formulas
- Data Visualization

## Dataset
The dataset contains 20 retail sales transactions with:
- Order ID
- Date
- Product
- Region
- Sales
- Quantity

## Key Performance Indicators (KPIs)
- Total Sales: ₹8,23,000
- Average Sales: ₹41,150
- Total Orders: 20
- Total Quantity: 64

## Dashboard Features
- Sales by Region
- Sales by Product
- Monthly Sales Trend
- Interactive Region Slicer
- Interactive Product Slicer
- PivotTable Analysis

## Project Structure
- Sales_Dashboard.xlsx

## Objective
To analyze retail sales performance and present useful business insights through an interactive Excel dashboard.
